# 방탈출 예약 관리 — Spring MVC 인증

로그인 인증과 로그인 회원 기반 예약 생성, 관리자 페이지 접근 제한을 구현합니다.

## 1단계 — 로그인

### 구현 내용

- 이메일과 비밀번호로 회원을 조회합니다.
- 로그인 성공 시 JWT를 발급하고 `HttpOnly` 쿠키에 저장합니다.
- 쿠키에 담긴 토큰을 검증해 로그인한 회원 정보를 조회합니다.
- 로그아웃 시 토큰 쿠키를 만료시킵니다.

### 주요 API

| 메서드 | 경로 | 기능 |
| --- | --- | --- |
| POST | `/login` | 로그인 및 토큰 쿠키 발급 |
| GET | `/login/check` | 로그인한 회원 정보 조회 |
| POST | `/logout` | 토큰 쿠키 만료 |

## 2단계 — 로그인 리팩터링

### 구현 내용

- `LoginMember`에 로그인한 회원 정보를 담습니다.
- `HandlerMethodArgumentResolver`를 구현해 쿠키에서 토큰을 추출하고 회원 정보를 조회합니다.
- 컨트롤러는 매개변수로 `LoginMember`를 받아 사용합니다.
- `WebMvcConfigurer`를 통해 ArgumentResolver를 등록합니다.

### 예약 생성

`POST /reservations` 요청 시 로그인한 회원 정보를 활용합니다.

| 요청 조건 | 예약자 선택 |
| --- | --- |
| `name`이 있으면 | 해당 이름으로 조회한 회원 |
| `name`이 없거나 공백이면 | 로그인한 회원 |

## 3단계 — 관리자 기능

### 구현 내용

- `HandlerInterceptor`를 구현해 컨트롤러 실행 전에 관리자 권한을 검사합니다.
- `/admin`과 `/admin/**` 경로에 Interceptor를 적용합니다.
- 토큰을 검증하고 조회한 회원의 역할이 `ADMIN`인지 확인합니다.
- 접근 권한이 없으면 요구사항에 따라 `401 Unauthorized`를 반환하고 요청 처리를 중단합니다.

### 접근 정책

| 사용자 상태 | 관리자 페이지 접근 |
| --- | --- |
| 관리자 | 허용 |
| 일반 회원 | 401 반환 |
| 비로그인 | 401 반환 |
| 유효하지 않은 토큰 | 401 반환 |

## 테스트

`MissionStepTest`에서 다음 항목을 검증합니다.

- 로그인 후 토큰 발급 및 회원 정보 조회
- 이름 생략 시 로그인한 회원으로 예약 생성
- 이름 지정 시 해당 회원으로 예약 생성
- 비로그인 및 유효하지 않은 토큰의 예약 생성 실패
- 관리자 페이지의 관리자 접근 허용 및 일반 회원 접근 차단
- 비로그인 및 유효하지 않은 토큰의 관리자 페이지 접근 차단
- 비로그인 사용자의 일반 페이지 접근 허용

### 실행 방법

Windows PowerShell:

    .\gradlew.bat test

테스트는 8080 포트를 사용하므로 해당 포트에서 실행 중인 애플리케이션을 종료한 후 실행합니다.
